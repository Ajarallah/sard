# سَرْد (sard)

عائلة مهارات لـClaude تشرح أي مادة شرحًا سرديًا متسلسلًا: تبدأ من الأساس، ثم تتنقل بين المحطات بروابط منطقية صادقة (أولًا، ولهذا، ثم يتضح، ومن خلال ذلك...)، حتى تصل إلى المعنى النهائي. تشرح بلغة المستخدم، وتراعي مجال الموضوع ومصطلحاته وسياقه.

## الأوامر
| الأمر | ماذا يفعل |
|---|---|
| `/sard` | النواة: الشرح السردي لأي نص أو فصل أو فكرة |
| `/sard-slides` | يجرد السلايدات كاملة (النص، والنوتات، والتعليقات، وخط اليد بالعربية والإنجليزية) ثم يشرحها من البداية |
| `/sard-roots` | يشرح من الجذور: لماذا وُجدت الفكرة، وكيف تطورت، وأين تقع من مجالها، ثم المادة نفسها |
| `/sard-book` | يبحث عن الكتاب وما قيل عنه، ويرسم خريطته السردية، ثم يشرحه فصلًا فصلًا |
| `/sard-article` | يمهّد بما يفترضه المقال من خلفية، ثم يفكك حجته ويشرحها |
| `/sard-deck` | يحوّل الشرح إلى عرض تقديمي: `مذاكرة` أو `تقديم` أو `كلاهما` |

الأوامر تتركّب: `/sard-roots` على ملف سلايدات يجرده أولًا ثم يشرحه من الجذور، و`/sard-deck` بعد أي شرح يحوّله إلى عرض.
في Claude Code تظهر الأوامر بصيغة `/sard:sard-slides`، ويكفي أن تكتب `/sard` لتظهر كلها.

## التثبيت كإضافة (للخطط المدفوعة: Pro / Max / Team / Enterprise)
1. في Claude افتح **Customize** ثم **Plugins**.
2. اضغط **Add** ثم **Add marketplace** ثم **Add from a repository**.
3. اكتب `Ajarallah/sard`.
4. ثبّت إضافة **sard** من القائمة.

**Claude Code:**
```
/plugin marketplace add Ajarallah/sard
/plugin install sard@sard
```

## التثبيت كمهارات مفردة (كل الخطط، ومنها المجانية)
1. نزّل ملفات `dist/*.zip` من هذا المستودع. `sard.zip` هو النواة التي تعتمد عليها البقية، فلا تستغنِ عنه.
2. فعّل **Code execution and file creation** من Settings ثم Capabilities.
3. افتح **Customize** ثم **Skills**، واضغط **+** ثم **Create skill** ثم **Upload a skill**، وارفع كل ملف على حدة.

## قراءة السلايدات
يستعمل `/sard-slides` السكربت `scripts/extract.py` لاستخراج النص والنوتات والتعليقات، ولتحويل الشرائح إلى صور يُقرأ منها خط اليد. يحتاج Python 3 ومكتبة PyMuPDF (`pip install pymupdf`)، ولتحويل ملفات pptx إلى صور يحتاج LibreOffice. فإن لم يتوفر فصدّر الملف إلى PDF من PowerPoint أو Keynote.

## للمطوّر
- فحص السكربت: `python3 plugins/sard/skills/sard-slides/scripts/extract.py --self-check`
- بناء ملفات الرفع المفرد:
```
cd plugins/sard/skills && for s in */; do (rm -f ../../../dist/${s%/}.zip && zip -qr ../../../dist/${s%/}.zip ${s%/} -x '*/__pycache__/*' '*.DS_Store'); done
```
